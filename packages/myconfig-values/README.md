# Config Values

Part of the [package-wrapped remote configs template](https://github.com/spautz/remote-config-template).

This project provides the <span style="font-variant:small-caps;">json</span> values which the [<span style="font-variant:small-caps;">sdk</span> package](https://github.com/spautz/remote-config-template/blob/main/packages/myconfig-sdk/README.md)
consumes. The config files would typically be deployed to a static host, like S3.
